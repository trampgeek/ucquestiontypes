RoboTurtle Help

Creating a RoboTurtle

Each robot in the world is shown on the grid, labelled with its name. Your code must create a RoboTurtle object for each one, giving its name as a string (names are case-sensitive), e.g.

alice = RoboTurtle("Alice")
bob = RoboTurtle("Bob")

The object then controls the robot of that name. Each RoboTurtle has its own position, heading and inventory, and you command it by calling its methods, e.g. alice.move() or bob.turn_left(). The name is required: it is the one written under each robot on the grid.

  • RoboTurtle(name) - create the RoboTurtle for the robot with the given name (a string).

In the descriptions below, t stands for any RoboTurtle object, e.g. alice.

Command methods
  • t.move() - move one cell forward. It's an error if there's a wall, a blocked cell or another robot in the way
  • t.turn_left() - rotate 90 degrees counterclockwise
  • t.turn_right() - rotate 90 degrees clockwise
  • t.take() - pick up an item from the current cell, place it in the inventory, and return its type name (e.g. 'star')
  • t.put() - place the least-recently-picked up object in the current cell and return its type name
  • t.toss() - place the least-recently-picked up object in the cell directly in front of the current cell (even if there's a wall in between), and return its type name
  • t.send_text(s) - display the string s, prefixed by the robot's name and a colon, in the text bar below the grid (only usable if this test supports it)
  • t.print_state() - print the robot's position and heading.
  • t.speed(n) - set this robot's speed to n where n is in the range 1 - 10 (slow to fast). n = 0 for max possible speed.
State-checking boolean methods
  • t.at_goal() - true if the goal for the whole world is currently satisfied
  • t.front_is_clear() - true if the robot is able to move forward
  • t.right_is_clear() - true if the cell to the right is clear
  • t.wall_in_front() - true if there's a wall in front
  • t.wall_on_right() - true if there's a wall to the right
  • t.object_here() - true if there's an object in the current cell
  • t.carries_object() - true if the inventory is non-empty
  • t.is_facing_north() - true if the robot is facing north
State-query methods
  • t.position() - return the robot's current grid coordinates as an (x, y) tuple
  • t.target_cell() - return the target cell's coordinates as an (x, y) tuple, or None if no target is defined
  • t.inventory() - return a new list containing the type names of items in the inventory, ordered by when they were picked up (most recently picked up last)
  • t.facing() - return the robot's current heading as 'N', 'S', 'E', or 'W'
Global function
  • speed(n) - set the speed of all the robots at once (same range as above)
